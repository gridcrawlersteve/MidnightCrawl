Keyboard, saves, and help

First visit: S)TART GAME → E)DGE OF TOWN → T)RAINING GROUNDS. Enter a new name, choose Y to create, and press Return twice for no password. Choose race and alignment; use +/− to spend bonus points, Return to change stat, and Escape when all points are spent. Select an available class and confirm Y. Create up to six adventurers, then add them at Gilgamesh's Tavern. Buy equipment at Boltac's and equip it before entering the maze. The front three characters fight in melee; the back three can cast or parry. Menu actions follow the original Wizardry controls.

Dungeon: W/F forward, A/L left, D/R right, K kick door, C camp, S status, M map. In combat: F fight, S spell, P parry, R run, U item, D dispel. Type spell names in the text field. The buttons below provide all letters and digits for every original prompt.

Your complete session saves automatically on this device after actions and timed transitions. Each scenario has a separate save. Export a backup before clearing browser data. Import accepts a Midnight Crawl v0.5 JSON backup for the selected scenario. Utilities also use these browser file pickers. Scenarios II and III use transferred characters: choose U)TILITIES → T)RANSFER to copy a saved roster from another scenario.
